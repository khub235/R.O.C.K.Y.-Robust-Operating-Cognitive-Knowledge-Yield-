# R.O.C.K.Y.-Robust-Operating-Cognitive-Knowledge-Yield-
s a Python-based AI assistant with a PyQt6 desktop interface featuring a futuristic dark/red design and an HTML, CSS, and JavaScript dashboard. It includes modular automation tools, system control, file processing, reminders, messaging, navigation, and JSON-based long-term memory, powered by Google Gemini via AI Studio API.
